Potterton Myson


I worked as an Analyst Programmer using VAX VMS Powerhouse Rdb, InQuizitive, SERVASURE package, Microsoft Visual BASIC providing support and maintenance for a Service System and development on a Sales Order Processing system. Using Powerhouse Rdb we developed a relational database reporting system around the SERVASURE boiler maintenance system. The database design was controlled by a full time DBA who allocated variable names and maintained the structure of the relational database and the Powerhouse data dictionary. Powerhouse used the data dictionary to generate simple screens and reports and provided the structure for the Inquizitive report generator which was very popular with the user base. More complex screens required some hand coding to support business logic that was missing from SERVASURE.
