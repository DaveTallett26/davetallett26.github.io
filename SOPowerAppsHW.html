Getting started with Microsoft Power Apps - Hello World



This is what Claude produced when asked - "please write the "Hello World app" for Power Apps" 
  Power Apps is low-code, so a Hello World app is a few controls and one formula rather than a code file. Here's the simplest version, built as a canvas app.
**Steps**
1. Go to make.powerapps.com and sign in.
2. Select **Create**, then **Blank app**, then **Blank canvas app**. Name it `HelloWorld` and choose **Tablet** or **Phone** format.
3. Select **Insert**, then **Text label**. Set its **Text** property to:
   ```
   "Hello, World!"
   ```
4. Select **Insert**, then **Button**. Set its **Text** property to `"Click me"`.
5. Select **Insert**, then **Text input**, and rename it `txtName` in the Tree view.
6. Set the button's **OnSelect** property to:
   ```
   Set(varGreeting, "Hello, " & If(IsBlank(txtName.Text), "World", txtName.Text) & "!")
   ```
7. Change the label's **Text** property to:
   ```
   If(IsBlank(varGreeting), "Hello, World!", varGreeting)
   ```
8. Press **F5** (or select the Play button) to run it. Click the button with the text box empty, then again after typing a name.

**What's happening**

- `Set()` creates a global variable, `varGreeting`, when the button is clicked.
- The label reads that variable, and shows "Hello, World!" until the button has been pressed.
- `IsBlank()` makes it fall back to "World" if no name is entered.

**Minimal version:** If you want just the bare minimum, skip steps 4 to 7. A single label with `"Hello, World!"` as its Text property is a complete Power Apps Hello World.

When you're ready, select **File**, then **Save**, then **Publish** to make it available to others.

Screens:
  Screen1:
    Properties:
      Fill: =RGBA(248, 249, 252, 1)
      LoadingSpinnerColor: =RGBA(56, 96, 178, 1)
    Children:
      - GreetingLabel:
          Control: Label@2.5.1
          Properties:
            Align: =Align.Center
            Color: =RGBA(34, 39, 49, 1)
            Font: =Font.'Open Sans'
            Height: =72
            Size: =32
            Text: =If(showGreeting, "Hello again!", "Hello, World!")
            Width: =Parent.Width
            X: =0
            Y: =Parent.Height / 2 - 80
      - GreetingButton:
          Control: Classic/Button@2.2.0
          Properties:
            Fill: =RGBA(56, 96, 178, 1)
            Font: =Font.'Open Sans'
            Height: =48
            HoverFill: =ColorFade(Self.Fill, -20%)
            OnSelect: =UpdateContext({showGreeting: !showGreeting})
            Text: =If(showGreeting, "Start over", "Say hello")
            Width: =180
            X: =(Parent.Width - Self.Width) / 2
            Y: =Parent.Height / 2 + 12
